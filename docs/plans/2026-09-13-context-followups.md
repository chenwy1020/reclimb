# 重登 0.4.6：围绕原内容继续学习

用户已确认实施历史内容追问、缓存优化和教材配合学习。沿用小版本定向验收与私有预发行，不调用私人材料做开发接口测试。

## 行为与边界

1. 已走过的解释与示范提供“继续追问”“为这段举例”；已收到的回应及沿途帮助提供追问。每个入口显示所针对的内容，先保存本机再回应。新追问有新记录，回应失败复用记录重试。
2. 后端按原步骤、消息或教材片段标识解析上下文，冻结版本与来源。连续追问读取该支线的问答以及相关争议、纠正，不误用当前新任务。当前任务、草稿和主线位置保留；帮助关联实际涉及的题目，讨论不生成能力证据。
3. 学习桌从选中的材料页段提供“从这段原文提问”。当前小版本使用已存在的学习会话；无会话时仍可阅读材料。教材旁提供可折叠的学习方法说明：阅读原文、形成自己的解释、按卡点求助、独立尝试与跨日回访。建议可以按基础调整，不作为强制关卡。
4. 记录服务商实际返回的缓存命中/未命中输入量和调用耗时，历史未知不算零命中。设置中按已报告样本展示比例与统计范围。费用继续按原输入价保守估算，不虚构折扣或节省。
5. 对请求中稳定规则、结构、来源和任务安排稳定顺序，把本次输入和变化历史置后；不删相关材料、纠正和必要核验，不混合生成和评价的独立上下文，不重复使用旧答案。

## 分工与验证

- 后端：锚点解析、消息关联、冻结来源、回应上下文、帮助记录、兼容与备份检查；针对性测试覆盖不同锚点、重复点击、重试、切换任务、继续追问、非法跨项目目标。
- 界面：就地追问框、原文入口、返回原任务、教学方法说明；桌面模拟验证实际点击、保存、续问、草稿和位置稳定。
- 缓存：服务商统计解析、诊断与设置呈现、稳定输入排列；测试完整上下文保留、未知样本不误计、费用预留不减弱。
- 交付：0.4.6 版本、定向测试清单、累计全量桌面入口、安装包、源码与校验文件，私有 PR 验收并预发布。构建前冻结生产代码；不以模拟接口的缓存值声称真实命中率提高。

## 持续审查

追问是围绕具体困难继续理解，不能变成不断索取答案的唯一入口；保留亲自尝试与整理理解的动作。教材提供可核对的结构和依据，AI 提供引导及反馈。缓存指标服务费用和等待时间，不代替学习效果。
