# iPad 手写配套页实施计划

目标：按已确认第二方案交付 0.4.9：Windows 主动开启配对，Safari 手写、本地保存、多页、撤销与橡皮、主动提交并冻结原任务；不调用 AI，不识别或评分手写。

实现：主进程按需启动局域网 HTTP 服务，配对凭证放 URL fragment，电脑确认短码后授权单个浏览器；只提供指定任务和提交接口，不开放文件、模型或通用 IPC。局域网 HTTP 不加密，界面说明仅可信网络；不自动改防火墙。持久化任务授权及手写页使用独立集合，原稿不进入模型上下文或能力统计。停止服务/退出/恢复档案撤销设备令牌；重新配对后仍可提交保存在浏览器里的已授权旧任务。配对不进入备份。

客户端：独立打包静态页面，IndexedDB 按桌面安装与任务 ID 保存，笔输入优先、手指书写显式开关，触摸滚动与笔画分开；保存失败明确提示并可下载草稿。断网时已打开页面仍可写和下载；局域网 HTTP 无 Service Worker 离线冷启动承诺。请求只由点击提交触发，使用持久 requestId 保证重试幂等，发送期间修改形成下一次提交，不覆盖原输入。

步骤与责任：
1. 根代理建立共享数据类型、存储迁移、原稿保存、主进程与桌面入口。
2. 子任务实现 iPad 页面与 IndexedDB 草稿（独立 src/companion 和 scripts/build-companion.mjs）。
3. 子任务实现受限 LAN 传输服务及网络验收（独立 src/main/handwriting-server.ts）。
4. 补齐格式 8 备份、恢复与可读导出，旧版关联校验、删除项目联动。
5. 类型检查、输入和证据相关离线回归；隔离桌面＋浏览器验证配对/拒绝/多页/断线/重试/切换/重启/备份，不读取私人材料，不调用模型。
6. 构建 Windows 安装包、白名单源码、说明、验证记录和 SHA256；沿用私有仓库分支/PR/预发行交付。

设备验证限制：实际 Apple Pencil 压感、防误触、锁屏/后台回收、Safari 存储清理及 Windows 防火墙需用户设备验收；模拟测试不宣称覆盖这些。
