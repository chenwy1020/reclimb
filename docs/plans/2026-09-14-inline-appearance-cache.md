# 重登 0.4.7 实施计划

用户已批准直接实现三项需求。本次在现有独立工作树和 codex/v0.4.7-inline-appearance-cache 分支完成，不修改主工作区的个人文档。

目标：原位连续追问、本机阅读外观、保持完整上下文的缓存优化。

1. 追问：复用 inputId / rootInputId / parentMessageId 和冻结来源版本。把可定位支线从通用历史移到原内容容器；支线按时间展平，并在所选回应后提供输入，不无限缩进。找不到原入口的记录保留历史入口。复用记录卡的回应状态、重试与来源跳转。先保存、迟到回应、答案暴露逻辑保留。
2. 外观：独立 localStorage 偏好和订阅，启动前应用浅色/深色/系统；本机调整字号、行距、双栏比例。主题变量覆盖现有组件，PDF 不反色。与学习数据库、模型请求和备份隔离。
3. 请求：保留完整运行时 schema 和校验，把动态格式约束移至稳定材料之后；提供真实消息序列接口。同一追问支线冻结原上下文、追加父链问答，当前纠正仍优先生效。格式修复追加消息而不改写前缀。费用预留计入全部实际消息。
4. 统计：增加操作/模型配置/支线维度与输入输出、恢复次数、耗时和保守费用；旧字段未知。记录结构版本及本机前缀摘要/长度，不存请求全文，不伪造服务端命中。
5. 验证：先补关键行为回归，再实现；类型检查、相关离线测试、Electron 桌面检查（原位、切换、重启、主题、公式/PDF、缓存）。不运行本次无关的全量测试，新增套件列入后续大版本集合。
6. 交付：递增 0.4.7，源码白名单、私有 PR、预发行、安装包和校验值。真实模型测试仅使用自编材料且先查账本；若无真实调用明确报告未验证线上命中提升。
