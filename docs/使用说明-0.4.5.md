# 重登 0.4.5 使用说明

本版修复“这里没跟上”反复报 `steps.2.activity.instruction ... <=500 characters`，并区分原处补讲与主动换小任务。

## 安装与继续

退出旧版，运行 `Reclimb-Setup-0.4.5.exe`。回到原学习项目，继续使用“这里没跟上”。不需要重新建立路线、导入材料或重填密钥。数据库及备份格式仍为 7，原题、作答与证据不批量修改。

## 卡住时怎样选择

- **这里没跟上**：选择术语、理由、中间步骤或信息太多。系统围绕当前内容补讲，保留原任务、草稿和待继续的步骤。补充显示在“沿途的补充与帮助”。失败时选项保留，可以再试。
- **连续没跟上**：系统读取当前步骤此前的帮助，尝试定位更具体的卡点、换成具体对象或共同走一步，不把重复求助自动解释为全部基础不足。
- **换一个更小的入口**：主动安排一个较小尝试，保留返回原步骤的入口。题设可以完整包含原句、数值或公式，不再用 500／240 字硬限制代替认知难度。
- **换个例子／给一点提示／看完整示范**：继续保留。涉及当前题答案的内容仍记录帮助；求助次数本身不作为能力判断。

补讲不等于经过独立核验的正确结论。来源、题目或解释仍有疑问时，可以继续讨论或使用“这里可能有错”。帮助不会直接产生能力证据，原有核验与答案暴露约束继续执行。

## 小版本试用

按本次约定，小修只运行与变更有关的回归和桌面检查，尽快交付试用；新增回归保留到完整测试集中，大版本再运行累计全量测试。具体范围和未验证部分见 [验证记录](验证记录-0.4.5.md)。其他功能见 [0.4.4 使用说明](使用说明-0.4.4.md)。
