# 重登 0.4 开发与扩展

使用 Windows x64、Node.js 24 和锁文件安装依赖。开发资料目录必须与正在使用的学习档案分开。

```powershell
npm ci
node node_modules/electron/install.js
$env:RECLIMB_DATA_DIR = Join-Path $PWD '.local-test-data'
npm run dev
```

## 检查与交付

```powershell
npm run typecheck
npm test
npm run build
npm run test:desktop
npm run package
npm run package:source
powershell -ExecutionPolicy Bypass -File scripts/verify-package-v04.ps1
node scripts/verify-delivery.mjs
```

桌面测试沿用 0.3.1 的可靠性回归，并增加全书地图、路线提案、稳定学习单元、实质挑战、理解稿归因、跨单元推进和主线恢复。它使用临时档案、自制 PDF 与 `127.0.0.1` 模拟服务，默认不读取真实密钥、不连接外部服务。

`verify-package-v04.ps1` 把 NSIS 安装包作为归档解开，运行包内的实际应用；它不会执行安装器，因此也不代表全新 Windows 安装验证。源码归档由 `scripts/source-files.mjs` 白名单控制，私人教材、数据库、备份、日志、凭据和测试输出均被排除。

## 0.4 数据和接口

数据格式 5 增加 `routeVersions`、`learningUnits`、`learningPositions`、`teachingObservations`、`understandingDrafts` 和 `readingLayouts`。路线快照保留历史，学习单元使用稳定编号，主线位置只由主动进入、返回和推进更新。

- `route.generate` 首次建立路线，之后只创建变更提案；`route.adopt` 和 `route.dismiss` 显式处理提案。
- `lesson.start` 接受 `unitId`，默认恢复该单元的已有会话；`newAttempt` 显式建立新尝试。
- `session.nextStep` 支持 `challenge`、`advance`、`synthesize` 和 `consolidate`，并继续支持缩步、独立尝试和支线返回。
- `understanding.save` 是本地版本事务；`understanding.suggest` 产生带 AI 作者标记的建议。
- `readingLayouts` 把正文块、原页区域、确认转录及来源版本关联起来。

教学观察用于下一步选题，不是第二套能力标签。依赖被撤销题目或评价的观察会暂停；能力证据仍经过题目核验、帮助归因、延迟和迁移规则。

## 推进与来源边界

活动的 `demand` 描述操作种类、复杂度、新颖度、支撑程度与概念集合。程序可以拒绝没有实质提高的挑战，也可以在两次同类同层操作后要求改变方向；它不能仅凭这些字段证明任务真的更难。新增活动类型时应提供行为反例，而不是只测试字段存在。

原始 PDF 提取文字始终按纯文本处理。只有有效 Markdown/LaTeX 材料和人工确认转录进入数学渲染。来源质量改善不能回写旧教学版本；局部确认不能提升整页可靠性。

## 可选真实服务验证

`scripts/run-live-validation.mjs` 只接受显式账本目录、配置、自编材料和累计上限；默认预检，加入 `--execute` 才调用真实服务。0.4 开发与打包验证没有使用私人教材或真实模型请求。真实教学效果仍需跨日使用观察。
