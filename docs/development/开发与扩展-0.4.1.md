# 重登 0.4.1 开发与扩展

0.4.1 延续 0.4 的“全书地图—学习单元—教学活动”结构，新增独立的项目生命周期。`Project.trashedAt` 表示项目处于最近删除，`statusBeforeTrash` 保存恢复时应回到的状态。共享选择器统一决定正常项目与最近删除项目，避免各界面自行猜测可见性。

## 本机操作接口

- `project.trash` 只标记项目并保留全部关联。
- `project.restore` 先恢复中断删除留下的安全暂存，再清除删除标记并恢复原状态；路径冲突或原件缺失时保持删除状态。
- `project.purge` 只能处理已进入最近删除的项目。服务先验证所有材料路径都位于本项目目录，再把带材料编号清单的目录移动到 `deletion-staging`；数据库事务成功后才清理暂存文件，失败则回滚文件。
- 启动时使用同一服务恢复未提交的暂存、重试已提交删除的诊断清理，并清理已满 30 天的项目。无法确认归属的暂存不会被误删。
- 主进程在文本或视觉请求尚可发布结果时拒绝删除、恢复和永久删除，防止项目清理后产生孤立记录。

被删除项目不能继续生成路线、开始课程、读取材料、评分、回访或导出为单项目成果。完整工作区快照仍包含删除标记，供“设置—最近删除”和完整备份使用。

## 数据格式 6

SQLite `user_version` 与 `.reclimb` 备份格式均为 6。数据库格式 5 升级前生成 `pre-0.4.1-*.sqlite`；备份格式 1 至 5 继续可读。格式 6 的项目校验允许删除时间和原状态，完整备份包含项目材料；可读 Markdown 导出通过共享可见性规则排除最近删除。

## 检查与交付

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run test:desktop
npm run package
npm run verify:package
npm run package:source
node scripts/verify-delivery.mjs
```

桌面删除检查只在 `smoke-v041.mjs` 中启用，使用隔离资料目录和自制文本。它确认删除摘要、正常导航隐藏、完整恢复、二次确认、永久清理及另一个项目不受影响，并断言模型请求数不增加。
