# 重登 0.4.9 使用说明

本版增加 iPad 手写草稿纸：电脑阅读教材，iPad 用 Safari 书写推导、画图和提交原稿。iPad 不需要安装 App。手写原稿先保存，本版不自动识别、不评分、不调用模型，也不会因此增加模型费用。

## 升级

最终交付安装包为 `Reclimb-Setup-0.4.9.exe`。退出正在运行的旧版后安装。模型、预算及学习档案继续保留；数据库升级到格式 8 前，会在资料目录的 `upgrade-backups` 中自动保存旧数据库。

升级后请创建一份完整备份。新备份格式为 8，包含手写原稿及原任务关联，仍可读取格式 1—7。旧应用不能直接打开升级后的数据库或格式 8 备份，不能通过覆盖安装旧应用直接回降；需要回到旧档案时，应使用升级前的备份并单独保管本版新增的手写原稿。不要删除正在使用的资料目录来尝试降级。

原位追问、阅读外观和缓存设置沿用 [0.4.7 使用说明](使用说明-0.4.7.md)。设置卡片间距修复沿用 0.4.8。

## 第一次连接

1. 让电脑和 iPad 连接同一个可信的局域网，并在电脑打开需要学习的任务。
2. 在学习桌主作答框之前找到“用 iPad 写下推导”，点击“iPad 手写”。选择电脑当前使用的局域网地址，点击“开启 iPad 连接”。
3. 用 iPad 相机扫描二维码，在 Safari 打开；也可以把“复制配对链接”得到的链接发送到自己的 iPad。链接含临时配对凭证，请勿转发给别人。
4. 核对电脑和 iPad 显示的短码，电脑点击“允许这台 iPad”。只有电脑确认后，平板才能读取发送的任务或提交原稿。
5. 电脑点击“发送当前任务到 iPad”。iPad 采用这项任务后，打开它自己的草稿纸。

连接使用固定端口 `47149`，只在手动开启期间运行。Windows 防火墙如有提示，仅为可信的专用网络允许连接；软件不会自动修改防火墙。访客 Wi-Fi、设备隔离或端口被占用时，可能无法连接；先核对网络和电脑选择的地址。配对码约 10 分钟过期，可点击“换一个配对码”。

本版局域网连接使用 **HTTP，不加密传输**。电脑确认和临时令牌用于限制访问，不等于传输加密。只在可信的同一局域网使用，不要做路由器端口转发或公开配对链接。HTTP 下的网页不能承诺像已安装的离线 App 一样冷启动。

## 写、擦和整理草稿

- 默认使用 Apple Pencil 书写；可选择笔宽及墨绿、蓝、红色。需要用手指写时，主动开启“手指书写”。
- “橡皮”擦除整条笔画，误擦可以“撤销”，也可以“重做”。增加页面后，可以在同一份草稿中继续演算。
- “补充说明或疑问”是可选文字，和原稿一起保存，不会触发 AI。
- 注意页面中的保存状态。显示“已保存在本机”表示已写入这台 iPad 的当前浏览器；若保存失败，先保留页面、下载原稿备份，再重试。

原始笔迹保留在白色纸面上，电脑的深色主题不会把原稿反色。Apple Pencil 压感、防误触、书写延迟和锁屏后恢复，需要在你的实际 iPad 上验收，电脑模拟测试不能代替真实手感。

## 提交与切换任务

点击“提交这份手写”后，页面先冻结并保存本次提交，再发送到电脑；等待期间仍可继续写。随后新增的笔迹属于后续修改，不会改变已经发送的原稿。

提交范围可选择“全部页面”或“当前页”。单次最多 12 页，并检查笔迹数量及实际传输大小；超出容量时先下载备份，再选择当前页分次发送。待发送的那份原稿保持原来的范围，重试时不会偷偷换成后来修改的内容。

发送失败或未收到确认时，点击“重试发送已保存的原稿”。重试复用原提交编号，不会重复生成记录，也不会自动排队调用模型。重登保存原稿、当时的任务与来源版本、提交时间和帮助条件；电脑切换任务后，原稿仍关联发起时的旧题。

电脑发送另一任务时，iPad 会提示有新任务，由你决定是否采用。已有草稿保留在“本机保留的草稿”中，不因切题而清空。电脑学习桌的“已经收到的手写原稿”可以打开原稿、翻页，并核对当时的任务。

本版这些原稿均标记为 **“未识别、未评价”**。保存了手写、写了很多页或看过示范后完成，都不会自动记作独立完成、延迟验证或迁移验证。笔迹及补充文字暂不进入模型上下文；需要文字讨论时，可以继续使用电脑已有的作答和追问入口。

## 断网、重启与原稿备份

页面已打开时，即使暂时断网，也可以继续写和在浏览器本地保存；重新连接后主动重试发送。不要把“暂时断线可继续写”理解成浏览器被关闭或回收后一定能离线重新打开。

草稿按这台电脑的学习空间和原任务保存。关闭电脑上的连接、退出重登或恢复档案，会撤销原设备授权；重新开启和配对后，可继续提交同一学习空间中仍有效的旧任务。

重要原稿请使用“下载原稿备份”保存 JSON 文件。换浏览器或电脑地址变化后，在配对同一个学习空间后，可以通过“导入原稿备份”恢复该文件。待发送的原稿保留原提交编号；同一任务的草稿已存在时，导入不会覆盖它。不能把另一学习空间的任务静默改绑到当前空间。

浏览器清理网站数据、无痕浏览、存储空间不足、系统回收页面或电脑 IP 地址变化，都可能影响本机草稿的可见性和恢复。不要依赖浏览器作为唯一备份；先下载重要原稿并确认电脑已经收到，再清理数据或改变使用环境。

电脑完整备份包含提交到重登的原始笔迹，笔迹分别存放并校验完整性，不包含配对令牌或模型密钥。可读导出会内嵌 SVG 原稿，注明原题、来源、帮助和“未识别、未评价”；部分 Markdown 查看器不显示内嵌 SVG 时，使用完整备份在重登恢复查看。

## 本版范围

当前先解决“安心书写、先保存、主动提交、准确归档”。手写公式识别、AI 对笔迹的反馈、实时双端笔画同步、互联网远程连接以及原生 iPad App 均不在本版范围。
