# 重登 0.4.3 使用说明

本版修复模型配置的输出上限被限制为 131,072 token、填写 384,000 时无法保存的问题。请退出旧版后运行 `Reclimb-Setup-0.4.3.exe`。本版继续使用数据格式 7，不改变已有学习记录、模型选择、密钥或预算。

## 设置 DeepSeek Flash

进入「设置 → 模型配置 → 编辑」，使用官方接口时，模型名按当前文档填写 `deepseek-flash`，接口地址为 `https://api.deepseek.com`。

「单次回复上限（token）」现在支持 512 至 393,216 之间的整数。填写 384,000 可以正常保存。官方所说的最大 384K 在接口文档中明确为 393,216；上限不等于上下文长度，也不是每次请求必须输出的数量。

此处填写模型可用的输出上限。程序仍按任务需要选择实际请求长度，并在请求前预留费用：普通任务与连接检查使用较小额度，路线首次为 9,000 token，格式恢复最高为 12,000，均不超过所填上限。提高此设置不会自动触发调用，也不会把每次请求扩大到 384,000 token。

官方服务目前推荐 `deepseek-flash`；旧名称 `deepseek-v4-flash` 已作为兼容名称映射到 DeepSeek-V4.1-Flash。本说明更正 0.4.2 使用说明中的旧名称建议。软件继续保留你填写的名称，不静默替换模型。

## 保存、切换与恢复

保存配置后，可以点击「设为当前」或使用顶部「下一次请求使用」切换。修改上限本身不需要重新填写密钥，保存后关闭、重启及备份恢复均保留所填数值。超出范围或填写小数时会显示中文提示，原配置保持不变。

备份仍不包含密钥；恢复后的密钥处理、多个模型的独立配置、请求归属和费用规则沿用 [0.4.2 使用说明](使用说明-0.4.2.md)。新版导出的高上限配置请用 0.4.3 或更高版本恢复，旧版仍有 131,072 的校验限制。
