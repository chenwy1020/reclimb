# 重登 0.5.3 使用说明

本版为图片作答上传小更新。保留网页手写，不增加裁剪功能。

## 在 iPad 上提交截图

1. 在电脑学习桌开启 iPad 连接，扫码配对，发送当前任务；在网页采用该任务。
2. 在 Goodnotes 等软件中完成书写，用 iPad 系统截图并裁剪。
3. 回到重登网页，在任务下方的“上传作答图片”选择一张或多张图片。
4. 图片先保存在当前浏览器；用上一页、下一页核对内容。选错的图片可移除。图片页只预览，不在上面继续书写；“加一页”仍可创建手写页。
5. 点击“提交这份作答”。选择多张时默认提交全部页面；需要分次发送时可选择当前页。连接失败后保留冻结原稿，点击“重试发送已保存的原稿”即可，不会重复作答。
6. 电脑学习桌点击“查看原稿”，可识别、核对文字并获取回应，随后在回应下面继续追问。图片上传不自动请求 AI；识别需要现有视觉服务配置并遵守预算。

支持 PNG/JPEG，单张不超过 6 MB，图片合计不超过 16 MB，每份原稿最多 12 页；超过时请在 iPad 中分次截图、分份提交。图片原始字节和宽高比例保留，不把截图转换成假笔迹或自动补全公式。其他图片格式可以改用系统截图。

## 保存和升级

- 原图关联发送时的任务和题目版本。电脑切换题目，不会把原图悄悄改绑。
- 页面已打开时，断网可选择并保存图片；重新在线后再发送。断网重新打开网页仍未支持。
- 草稿在当前 iPad 浏览器中；请勿清除网站数据。重要草稿可下载原稿备份。选图本身不上传外部 AI。
- 图片识别仍是待核对转录。看不清的符号、图形必须保留疑点；保存原图或确认识别文字不等于证明推理正确。
- 数据库和备份格式升级为 10，升级前自动保留原数据库；读取旧版备份。已上传的原稿及对应的转录、回应、追问随完整备份和 WebDAV 档案保存。
- 多台电脑使用同一档案时，请都升级到 0.5.3 或更新兼容版本。旧版拒绝读取格式 10；不要降级后直接打开新版数据库。iPad 网页升级后刷新一次即可。

本版没有改动 Apple Pencil 绘制引擎，不宣称修复原有笔触体验。图片入口用于让你直接使用满意的书写软件。
