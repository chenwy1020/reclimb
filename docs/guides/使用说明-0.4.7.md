# 重登 0.4.7 使用说明

本版保留现有学习项目、题目、来源、草稿和证据。安装前退出旧版，再运行 `Reclimb-Setup-0.4.7.exe`。可先在设置中创建完整备份。

## 在原处继续追问

在当前内容、已经走过的解释与示范、AI 回应下点击“继续追问”或“为这段举例”。材料区的“从这段原文提问”位于原页或正文下方。

问题先保存在本机。待回应状态、回复和重试入口都留在该内容下方。对回复继续追问时，输入框在该回复下面，整条支线按先后顺序展示，不逐层挤窄正文。

主任务及其草稿保留。AI 忙碌、未配置或预算不足时，问题仍可保存，稍后点击“获取这条记录的回应”；不会自动排队计费。失败后点击“重试这次回应”复用原问题。历史原入口无法可靠定位时，记录保留在“已经留下的想法”，并提示原因。

已提交支线在重启及备份恢复后保留。当前输入框尚未提交的文字应先点击保存再离开。提出质疑不算获得提示；实际回应涉及当前题答案时仍记录帮助，不能因此把已看过答案的变体算成独立完成。

## 外观与阅读

打开“设置 → 外观与阅读”：

- 选择浅色、深色或跟随系统；默认跟随系统。
- 调整阅读字号（14–24 px）、行距（1.4–2.4 倍）、材料区比例（30%–65%）。窄窗口改为上下排列。
- 点击“恢复默认外观”恢复三项阅读参数及跟随系统模式。

外观即时生效，无需点“保存常规设置”。偏好只在本机保存，不进入 AI 请求、教学偏好或学习备份。Markdown、LaTeX 和作答区随外观调整；PDF 与原图公式保留原始颜色。

## 缓存与耗时

“设置 → 本月缓存与耗时”可按操作、模型配置和连续追问支线查看输入/输出、已报告缓存比例、耗时、格式恢复次数及保守费用。

命中率以服务商报告的输入 token 加权计算。未报告不算零命中，历史恢复类型与支线缺失保持未知。费用仍以普通输入价格保守估算，未扣缓存折扣，以服务商账单为准。

本版把动态返回格式放在原材料之后，保留全部结构约束和本机验证；连续追问追加父链消息，格式修复追加问题详情。已确认纠正和新增转录仍会更新讨论上下文。前缀摘要是本机诊断信息，不是服务商命中证明。

无需为缓存改变学习方式。新主题、核验上下文和来源修订应按学习需要发生；不要为了百分比保留失效解释或延迟纠正。

## 验证边界

本版采用原创材料和本机模拟服务验证功能，未新增真实 AI 费用。实际缓存命中率、费用下降和教学效果仍需在真实学习中观察，不保证某个百分比。安装包已完成解包运行验收；不将其表述为在全新 Windows 虚拟机完成安装测试。
