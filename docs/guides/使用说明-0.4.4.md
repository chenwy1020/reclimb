# 重登 0.4.4 使用说明

本版修复生成学习路线反复提示“能力引用了不存在的先修能力”或“学习单元引用了不存在的先修单元”的问题。退出旧版后运行 `Reclimb-Setup-0.4.4.exe`。升级保留数据格式 7，不改变模型配置、预算、材料、已有路线、作答或证据。

## 这次错误的原因

模型将“一元微积分”等背景知识填入只允许引用本路线能力名称的字段，或将能力名称当成学习单元名称使用。程序为了保留正确关联而拒绝发布，但此前给模型的格式说明没有明确区分这些含义。自动恢复只收到少量错误摘要，没有看到自己刚生成的路线，容易重新生成另一份不一致内容。

这类引用错误与输出容量不同，增大 token 上限不能直接解决。0.4.4 已在生成前明确能力、学习单元、地图节点的引用方式，以及历史编号的含义。

## 重新建立路线

打开原项目，使用原有的“建立学习路线”入口即可。已有路线时，使用“调整路线”，检查建议后再采用；不需要删除项目、重新导入教材或重填密钥。

发生格式或引用问题时，系统最多自动修复一次。恢复请求会带上有长度限制的原失败内容和具体问题，要求保留有效部分，修正引用并返回完整路线。恢复调用也计入预算；剩余额度不足时会停止，已有记录保留。

背景知识和未知先修作为相应单元的“待解决缺口”保留，供后续教学定位。未出现对应学习表现前，不会因为它出现在路线中就记为掌握或认定学习者不会。内部引用仍须指向确实存在的目标，来源与循环依赖检查继续执行。

诊断预览继续在设置中提供。若仍然失败，可查看具体引用错误；无需反复提高输出容量。模型仍可能返回错误，软件不会把未通过校验的路线覆盖到原路线。

多模型及输出容量设置沿用 [0.4.3 使用说明](使用说明-0.4.3.md)。本次变更的验证范围、真实模型费用及局限见 [验证记录](../verification/验证记录-0.4.4.md)。
