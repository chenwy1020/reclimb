# 重登 0.5.0 使用说明

本版继续配合教材使用：读原文、亲自尝试、核对手写，再根据反馈追问。同步和书写便利不代替来源核验或独立表现。

## iPad 连续书写

安装本版电脑程序，重新连接 iPad，并刷新原配对页面以载入新脚本。新增原生笔触接续与重复事件排除，处理笔输入只有一类事件、或浏览器提前取消事件的情况。

若开启系统“随手写”时仍选中界面文字，点击 **专注书写**：暂时收起任务正文、配对与补充文字输入区，保留画纸和书写工具；退出后回到原阅读位置。不要在落笔过程中切换模式。

“书写问题诊断”记录事件计数、最近事件顺序、绘制帧和重绘次数，以及屏幕尺寸与像素比；不包含笔迹坐标、题目、学习文字或配对信息。可以对照测试开启/关闭 iPad 系统的“随手写”，帮助区分系统文字输入接管。Air 5、二代 Pencil、开启随手写的实际连续笔画仍需用户设备复测；桌面引擎模拟不能保证真机行为。

原有手掌防误触、主动启用手指、撤销重做、分页、断网草稿和主动发送保持可用。重要原稿仍可单独备份。

同一任务若在两个标签页同时编辑，系统会在本机保存时核对各自的起点；两份内容冲突时另存“冲突副本”，不覆盖另一页的新笔迹。可从“本机保留的草稿”分别选择原稿与副本，下载或继续写。副本仍关联原任务，不自动合并、提交或调用模型。

## 对手写反馈继续追问

学习桌打开手写原稿，识别或手工核对文字并保存确认；收到回应后，在该回应下点击 **继续追问** 或 **为这段举例**。后续问答留在原稿的同一支线，可继续追问。

文字先保存在本机，再请求回应。没有网络、密钥或预算时仍保存；重试继续回应同一条输入。支线保留原手写、确认转录、原任务和原版本，不移动电脑正在进行的另一任务。没有可靠原版本、识别有疑点或题目未核验时继续探讨，不补造能力评价。实际揭示原题答案的反馈仍记录帮助条件。

## iPad 阅读任务

发送当前任务后，iPad 使用本地 Markdown 与 KaTeX 显示段落、列表、代码和数学式，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`。没有外部字体请求；坏公式保留原文并提示核对。原来已损坏的 OCR 符号不会凭空修复。任务中的 HTML、脚本、远程图片和主动链接不在平板执行。

## WebDAV 备份与多电脑接续

在 **设置 → WebDAV 备份与多电脑接续** 填写网盘提供的 WebDAV 目录地址、用户名、应用密码，以及同步空间编号。同一档案的每台电脑使用同一目录和空间编号；不同人的档案使用不同空间。本机名称用于辨认上传者。

1. 首台电脑保存连接，点击 **检查远端更新**，再 **上传当前完整档案**。
2. 另一台电脑配置同一空间，检查后 **预览远端档案**，核对项目、材料、会话及手写数量，再采用继续。
3. 结束学习时主动上传；回到另一台电脑先检查、预览再接续。本版不会在后台自动覆盖或自动合并两端同时修改的学习记录。

完整快照包含原始教材、学习路线、草稿、问答、帮助、争议、证据、理解稿、手写及转录。采用前会再次检查两端是否变化，旧本机档案保留在资料目录旁的 `previous-…` 目录。同步采用保留本机模型端点、密钥、价格、预算、外观；学习目标和偏好随档案接续。费用记录保留双方已记录条目，同编号不同内容时停止采用，因此不会通过恢复旧备份清空已计费额。

两端都修改时显示冲突：可以 **另存远端档案副本**，再明确选择采用哪份继续。采用远端不合并另一份分叉稿；旧档案仍单独保留。预览后又写了内容，必须重新预览确认。上传失败使用同一待重试快照，不会偷偷改成新的上传。

连接设置和密码只保存在本机，密码使用 Windows 系统加密；API 密钥、WebDAV 密码和外观不放入学习备份。默认 HTTPS。显式允许 HTTP 时，账号与学习档案以明文传输，仅适合可信网络。网盘上的学习快照本身是可读的备份文件，应使用本人控制的私有目录。

服务器须支持强 ETag 与条件写入；软件会用小型核对文件检查条件更新是否真实生效，不支持则停止安全同步。单份备份上限为 250 MB；本版不自动删除远端历史快照，删除项目后旧快照仍可能保留它。各次预览和未完成传输也保留在本机同步目录。iPad 尚未发送的草稿只留在该浏览器，换电脑前先提交并上传，或下载原稿备份。iPad 不通过 WebDAV 独立学习；电脑采用另一档案后请重新配对 iPad。

普通“从备份恢复”仍按原有规则清除本机 AI 密钥；WebDAV 接续使用单独的本机设置保护流程。

## 升级与边界

安装前退出旧版，运行 `Reclimb-Setup-0.5.0.exe`。数据库及备份继续使用格式 9，旧格式仍可读；旧版本升级数据库前保留原文件。不要将新支线记录拿给不能完整理解它的旧程序继续编辑。

本轮没有进行真实模型调用，不消耗开发模型额度。真实 Pencil 连写、你的 WebDAV 服务兼容性、识别准确率和教学质量需实际观察。测试记录见同目录验证文档；测试数量不证明已掌握教材。
