# 重登 0.4.10 · 手写连续输入与原稿反馈

电脑安装新版本后，iPad 上重新载入配对页面。iPad 仍不需要安装 App；已有原稿请先确认本机保存状态，重要内容可下载原稿备份。使用可信的同一局域网，连接方式与 0.4.9 相同。

## 连续写下推导

本版减少每一笔触发的重画与草稿复制，处理连续落笔时的浏览器捕获异常，并加强书写区周边文字的防选中。低压力的笔迹显示更清晰，保存的坐标与真实压力保留。手指书写开关、防误触、撤销/重做、离线草稿和主动提交继续保留。

如果实际 iPad 仍出现断笔，请在页面下载“书写问题诊断”，保留出错前后的操作描述。诊断只包含输入事件计数和窗口信息，不包含笔迹、原题、配对凭证或密钥。浏览器模拟检查不能代替 Apple Pencil 真机复测。

## 识别、核对与反馈

1. 在电脑学习桌的“用 iPad 写下推导”中，找到提交的原稿，点击“查看原稿”。卡片与学习区边框之间已增加留白。
2. 在原稿下方点击“识别这份原稿（计费）”。使用设置中的独立视觉服务，按原页顺序识别已保存的笔迹。不会自动识别新收到的原稿，也不会替换日常文字模型。
3. 对照原图核对文字、公式、页序和图形说明。可先预览公式；不确定的位置保留标记。识别只负责转写，不应补证明、改正原稿或替你解题。
4. 勾选核对声明后点击“保存确认文本并获取反馈”。先在本机保存确认版本，再请求回应。未配置服务、网络异常或预算不足时仍可保存；稍后在同一原稿下方主动获取或重试回应。
5. 回应使用原稿提交时的任务与来源版本。已切换到其他任务时，原稿反馈不会替换当前步骤或草稿。评价依据和限制可以在该原稿下展开；原始笔迹、机器识别、人工确认分别保留。

没有视觉服务也可以手工录入文字并核对。核对中的草稿会本地保存，关闭原稿、去设置或重启后可继续；核对声明不会自动勾选。修改确认文字会产生新版本，已有版本与作答不被覆盖。

机器识别不等于正确。仍有无法辨认的符号、未描述图形、来源疑点、未核验题目或争议时，只共同分析，不形成能力结论。原题获得的帮助继续保留，不能通过转成文字恢复“独立完成”。只有符合现有题目核验和证据条件的确认作答才进入评价。

识别与反馈分别计费，格式恢复也受现有预算限制。已保存的识别结果可以反复查看；“再次识别”会创建新识别版本并重新计费，不会自动进行。采用 [Fireworks 官方视觉接口](https://docs.fireworks.ai/guides/querying-vision-language-models)的图片输入格式；具体模型需支持图像，实际服务可用性与识别质量以你的调用为准。

## 升级与资料

学习数据库与完整备份升级到格式 9，首次升级前自动创建数据库副本；仍读取格式 1—8 的旧备份。完整备份与可读导出保留原稿、转录、确认作答及反馈关联，密钥不进入备份。旧原稿不自动发送给模型、不自动重新评价。

本版没有用私人教材或私人笔迹进行外发开发测试，也没有自动花费开发测试预算。模拟测试验证的是保存、请求、回应和错误恢复流程；实际识别准确率、延迟与真实 iPad 笔触体验仍需使用中验证。
