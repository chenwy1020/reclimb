# 重登 0.7.1 使用说明

0.7.1 是 0.7 知识图谱版的安全与可靠性维护版本。学习功能继续参考[0.7 使用说明](使用说明-0.7.md)，本轮核验依据见[评估报告逐项处理记录](../superpowers/review-2026-10-15.md)。

## 更新内容

- 加强备份读取的解压大小检查，并升级 ZIP 依赖。
- 开始或继续学习时，避免选中其他项目或无关回访的会话。
- 从“最近删除”恢复项目前检查材料原件，缺失时保留原状态并允许补齐后重试。
- 费用显示与请求拦截统一按本机日历月份计算；跨月未完成的预留仍计入预算。
- 非法帮助请求在写入帮助或答案暴露记录之前被拒绝。
- 刷新派生状态时不再额外读取全部手写图像。

## 升级与兼容

Windows x64 安装包为 `Reclimb-Setup-0.7.1.exe`。使用前关闭旧版重登，再运行安装包；通常可沿用已有安装目录。升级前请保留可用的完整备份。安装器本身的全新 Windows 安装和用户真实档案升级不属于自动验收结论。

本版未修改数据库与备份格式，仍为12；0.7生成的档案和备份继续适用。从0.5.3或0.6升级时，会经过既有格式迁移流程；多电脑接续应统一升级后继续使用。

完整备份仍受250 MiB压缩文件等边界限制，暂不支持分卷；不要通过删除学习记录来尝试绕过限制。真实模型教学质量、长期学习效果及实际iPad体验仍需分别验证。
