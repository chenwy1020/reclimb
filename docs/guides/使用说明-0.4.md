# 重登 0.4 使用说明

## 安装与升级

运行 `Reclimb-Setup-0.4.0.exe` 并选择安装目录。升级前退出旧版重登。首次打开既有档案时，程序先把升级前数据库原样保存到 `upgrade-backups`，再升级到数据格式 5。材料、题目版本、作答、争议、帮助与能力证据保持原关联。

应用资料保存在当前 Windows 用户目录。完整备份不包含教学或视觉服务密钥；在另一台电脑恢复后，需要重新填写密钥。

## 建立和调整学习路线

导入材料并说明目标、起点后，点击一次“建立学习路线”。路线页分为三层：全书地图说明核心问题和章节关系；学习单元保存可以跨多次会话的问题与成果；学习桌负责眼前的讲解、尝试和反馈。

地图会分别显示已经读入正文和尚待深入的页段。它是随学习修订的粗图，不代表 AI 已经通读或掌握整本书。“调整路线”先生成提案；只有点击采用，当前路线才改变。仍然适用的学习单元保留稳定编号，旧会话和理解稿不会被切断。

再次进入单元默认恢复上次会话和草稿。“另开一次尝试”才建立同一单元的新会话。首页和路线页的“继续学习”依据持久主线位置，不因后台回应或自动保存跳到别处。

## 继续、提高挑战和向前走

“按当前理解继续”会综合相关作答、讨论、质疑、帮助历史、理解稿和有效证据来选择下一步。连续出现同类、同等帮助和同层要求后，系统应提高要求、转向后续内容，或指出仍未解决的具体缺口。

觉得太简单时，可以选择“太简单，增加挑战”。有效挑战应从辨认或代入提升到解释、推导、条件比较、多概念连接、新情境迁移或综合；只换数字、名称和题量会被程序拒绝。长证明、分析和作品可以跨会话完成，并显示阶段目标。

“进入下一单元”不会把当前单元伪造为已掌握。挑战未完成时，后续只补这次实际暴露的缺口；题目错误和来源不确定也不会被解释成基础薄弱。学习者仍可主动选择巩固、暂停或探索支线。

## 理解稿：读厚与读薄

学习桌中的“整理我的理解”保存当前单元的理解版本。选择“读厚”时，可写解释、联系、例子、反例、推导和疑问；选择“读薄”时，可重组核心问题、关键条件、证明骨架和适用边界。两者可以随时往返。

本机保存不会调用 AI，也不产生能力证据。请求 AI 整理会另存一版并标为“AI 建议”；以它为底稿修改后的版本标为“我修订了 AI 建议”。采纳建议不等于独立重构。已有作答和来源可以继续追溯。

## 阅读数学材料

PDF 的“原始页面”始终可以缩放并按实际页码跳转。原生文本的“可读文字”采用纯文本重排，不会把断行中的 `+`、编号或符号解释成 Markdown 列表，也不会把普通 OCR 字符猜成 LaTeX。

检测到隐藏 OCR、图像页、图表或不可靠公式时，原页成为主要阅读依据，原始提取只用于搜索和对照。可以手工录入整页或所选区域并确认；整页确认转录可以使用 Markdown 与 KaTeX，局部确认只替对应区域建立新版本。阅读界面与 AI 取材遵守同一来源版本规则。

## 保存、质疑、评价与费用

每次输入先在本机保存，再请求回应。无密钥、零预算、断网、核验未通过或 AI 正忙时仍能保存。题目有疑点时进入共同分析并暂停能力评价；确认纠正会形成新版本，不改写旧作答面对的内容。

本机写理解稿、阅读、切换位置和只读检查不产生模型费用。路线生成、教学回应、AI 整理、格式恢复和主动核验会计入本机预算。程序核验只能降低已知错误风险，不能认证模型或教材中的数学结论。
