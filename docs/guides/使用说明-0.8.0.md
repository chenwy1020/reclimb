# 重登 0.8.0 使用说明

0.8.0 调整学习台、回访和首次配置。资料与排程留在本机，无需自建服务器。原有学习关联、材料与手写说明继续见 [0.7 使用说明](使用说明-0.7.md)。

## 安装与升级

Windows x64 安装包为 `Reclimb-Setup-0.8.0.exe`。升级前导出完整备份并退出旧版，再运行安装包。已发布的 0.7.1 文件保留。本版仍使用数据库与备份格式 12；多电脑接续请一起升级。新增回访状态不能保证旧版本正确理解，不建议往返降级。

安装包包含运行环境。首次启动可从首页打开原创示例，未连接模型也可阅读并保存首次尝试。需要 AI 时，进入“设置 → AI 与费用”，在快速连接中填写兼容服务地址、模型名称、密钥与预算，测试后启用。已有模型配置会保留。费用使用配置中的估算价格，实际账单以服务商为准。

## 学习台

- 打开后先看到当前任务、作答区和一个主按钮。公式输入可实时预览。
- 反馈紧接作答区，只显示一次；展开后查看原答、标准和详细条件。
- “学习工具”中提供材料、求助、笔记、追问、规划、会话与核验详情。关闭后仍保留草稿和阅读位置。
- 独立尝试默认专注作答。主动退出后可以使用材料和帮助，实际帮助仍记入本次表现。这不是正式的开卷/闭卷考试模式。
- 学习记录按能力分组；关联详情里的图明确标为“证据溯源图”，支持完整名称与滚动查看。

## 连续回访

通过独立尝试后安排后续回访，间隔按 1、3、7、30、90 天逐步拉长。无帮助通过可延长，有帮助完成维持当前间隔，明确失败后约 24 小时再次复学；评分不确定时不擅自改期。

旧档案已有的 +1/+7 邀请保留，完成旧队列后续接新排程。撤回、暂停、归档或依据失效时，相应记录不再用于排程。首页显示到期数量、预计时长和本周按期无帮助通过次数；队列交错呈现不同能力。

回访生成要求为一个短任务、最多两项标准，预计约 4 分钟。模型输出不合结构时会尝试一次修正；修正仍不合要求就保留失败，不能把超长题当成短回访发布。

## 本机提醒

在学习设置中启用回访提醒并选择时间。默认关闭，启用后只在应用运行且有到期项目时，每天最多提醒一次。退出应用后不会提醒；不需要服务器或系统计划任务。
