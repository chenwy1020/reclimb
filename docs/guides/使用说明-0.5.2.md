# 重登 0.5.2 使用说明

本次修复坚果云 WebDAV 上传时“条件写入核对未获得可靠强 ETag”的兼容问题。学习数据库与备份格式仍为 9；现有配置、待上传快照及学习记录沿用。

## 升级与重试

1. 退出正在运行的重登，安装 Reclimb-Setup-0.5.2.exe。
2. 设置中展开“WebDAV 备份与多电脑接续”，点击“检查远端更新”。
3. 如果显示“重试上传同一快照”，点击它继续此前已保存的档案，无需删除同步目录或重新配置密码。
4. 旧快照上传成功后，如果仍显示本机有新修改，说明失败后继续学习的内容尚未上传。再次上传当前完整档案即可。

另一台电脑需要使用同一网盘地址与同步空间编号，先检查、预览，再明确采用远端档案。不自动合并两台电脑分别产生的学习修改。

## 修复原理

坚果云实际返回不带引号的版本标记；普通“文件已存在时禁止创建”请求未能阻止覆盖。软件现在对坚果云官方 HTTPS 地址保留原样版本标记，使用“不覆盖目标的文件移动”发布新文件，使用版本条件更新已有主版本。上传前会用小测试文件核对这些行为，不以服务商名称代替实际验证。

普通标准 WebDAV 服务继续使用原来的严格条件写入。缺失标记、弱标记、内容不一致、不执行防覆盖或不拒绝过期版本时仍暂停上传。首次检查只表示目录与远端记录可读取；上传时才执行兼容性检查。

## 诊断与边界

失败会说明读取状态、版本标记问题、内容问题或版本保护失败。展开设置中的“出问题时，留下可以检查的线索”，预览 WebDAV 同步诊断；只包含请求方法、资源类别、HTTP 状态、标记类别和失败原因，不包含密码、实际标记值、地址或档案正文。

中断或取消保留本机待上传快照，重试沿用原编号。异常断开可能留下本次独立临时文件，不把临时文件当成可接续版本，也不会自动清除历史完整快照。真实网络仍受速度、容量和服务商限制；本版没有上传用户私人档案替用户验证。

设置折叠、iPad、学习与原有备份操作见 [0.5.1 说明](使用说明-0.5.1.md) 和 [0.5.0 说明](使用说明-0.5.0.md)。
