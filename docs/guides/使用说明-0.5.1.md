# 重登 0.5.1 使用说明

本次为小版本：修复 WebDAV 首次目录初始化，改进连接编辑，设置功能卡片默认折叠。学习档案与备份格式仍为 9。

## 设置卡片

进入设置后，外观、模型、原页识别、费用、学习节奏、WebDAV、最近删除、诊断及本机备份共九张功能卡默认折叠。点击标题或箭头展开，再次点击收起；键盘聚焦标题后可用 Enter 或空格。

收起卡片保留当前页尚未保存的表单输入；保存仍使用各功能原来的保存按钮。离开设置或重启不保存尚未提交的设置输入；再次进入默认折叠。折叠状态不会进入学习档案、备份或模型上下文。

## 修改 WebDAV 连接

展开“WebDAV 备份与多电脑接续”，点击 **修改连接**，编辑后点击 **保存本机同步连接**。同一地址和用户名下，密码留空保留原密码；修改地址或用户名时必须重新填写应用密码。点击“收起连接编辑”保留当前页未保存的输入。

本机连接读取失败时可点击 **重新读取本机连接**，此操作只读取本机，不请求网盘或模型。

## 首次上传

1. 保存连接后点击 **检查远端更新**。
2. 远端尚未建立重登目录、读取版本返回 HTTP 409 时，软件按父目录顺序准备应用目录，然后重新读取；这个阶段不上传学习档案。
3. 显示“远端空间没有快照”后，点击 **上传当前完整档案**。

正常已有档案的检查保持只读。上传会先准备所需目录，再检查远端版本和条件写入能力。配置的基础目录必须已经存在且可访问；例如服务商提供的 WebDAV 根目录，不要填写未创建的自定义路径。程序只创建该目录下的重登子目录。

目录准备后仍返回 409、没有权限、重定向、没有可靠版本标识或不支持条件写入时，软件继续报错，不覆盖远端内容。依据提示修改连接或处理网盘限制后主动重试。费用、密码保护、同步冲突与旧档案保留规则沿用 [0.5.0 使用说明](使用说明-0.5.0.md)。

## 升级

退出运行中的重登，安装 `Reclimb-Setup-0.5.1.exe`。原有学习记录、模型与 WebDAV 配置沿用。安装后展开同步卡片，检查远端再上传。

本轮只使用原创学习档案与本机模拟 WebDAV 验证，没有真实模型调用、没有上传私人档案。真实网盘仍需按上述流程验证；本地通过不等于已经认证所有网盘兼容性。
