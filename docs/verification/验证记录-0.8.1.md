# 0.8.1 设置布局补丁验证

日期：2026-10-23。修复 0.8.0 设置页面的两处布局遗漏，运行期改动限于提醒组件结构和设置样式。

- “数据与同步”采用统一 18px 纵向间距，说明卡片与 WebDAV 卡片不再贴边。
- 回访提醒补齐卡片边界、标题与说明间距；时间框和保存按钮间隔 12px，空间不足时换行。提醒仍直接显示。
- 模型调用、提醒保存逻辑、数据库及备份格式不变；0.8.0 已发布标签和附件保留。

## 实际验证

- 修复前在隔离档案中复现：说明卡片与 WebDAV 的间距为 0，提醒控件间距缺失。
- 修复后完成 56 组布局测量：浅色与深色，1440×900、1280×800、1040×800，以及 1280×800 的 125% 页面缩放；覆盖三类设置的展开与折叠，以及回访提醒。无卡片贴边、控件重叠或页面横向溢出。
- 提醒时间改为 20:15、保存、重载后仍保留；隔离档案中的提醒保持关闭。7 项提醒与外观单元测试通过。
- 42 项交付检查通过，覆盖 0.8.0 默认验包入口与 0.8.1 参数入口的成功和失败路径；格式检查通过，静态检查为 0 错误、88 项既有警告。
- 本机截图和测量保存在 `output/playwright/settings-layout-before/` 与 `output/playwright/settings-layout-after/`；临时验证脚本为 `output/verify-settings-layout.mjs`，均不进入源码归档。

安装包及发布检查结果以随包 `Reclimb-Verification-0.8.1.json` 为准。
