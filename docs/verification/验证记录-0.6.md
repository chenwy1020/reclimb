## 最终交付的复现方式与使用边界

- 本地执行 `npm run typecheck`、`npm test`、`npm run build`、`npm run test:desktop:full`。累计脚本含旧版流程以及阅读续接、识别恢复和 0.6 新入口；版本组有重叠，不合计成独立需求数量。
- Windows 安装包使用固定版本 0.6.0 的最终构建；`npm run verify:package` 从 NSIS 包中提取程序，核对依赖后用隔离档案执行实际打包程序。不运行安装向导、不覆盖已安装程序或正式学习档案。
- `npm run package:source` 按明确清单收集源码、测试、脚本和文档，附 `SOURCE-MANIFEST.json` 的逐文件 SHA-256。源码包不包含个人档案、凭据、依赖目录和测试生成文件。
- 交付 `Reclimb-Setup-0.6.0.exe`、`Reclimb-Source-0.6.0.zip`、`SHA256SUMS.txt`。校验值单独提供，避免源码包内自引用哈希。
- 格式 11 自动升级会先备份旧数据库。此处只对隔离档案完成升级／回滚验证，没有打开正式档案进行升级。
- 真实设备、真人跨日和真实模型质量继续使用上述记录模板，亦可在“独立验证”中保存试用记录并导出。报告只描述系统记录及用户自述范围内的独立性，不生成统一掌握分。
