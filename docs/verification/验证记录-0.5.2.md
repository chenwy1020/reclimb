# 重登 0.5.2 验证记录

本版是 WebDAV 兼容修复的小版本，仅运行相关测试和桌面流程。原有全量入口保留，新增检查并入下次大版本完整集合；不以软件检查代替学习效果验证。

## 根因与实现

使用不含学习内容的小文本核对真实坚果云：GET 200 且正文匹配，但 ETag 无双引号；原样 If-Match 更新成功并拒绝旧版本（412）；加引号会被拒绝；If-None-Match:* 未阻止覆盖；LOCK 未实际拒绝无锁写入。因此本版不使用文件锁，也不简单放宽格式后沿用普通 PUT 创建。

MOVE Overwrite:F 首次发布返回 201，目标存在返回 409且原文不变。仅官方 HTTPS 主机启用经实际核对的兼容路径：MOVE 不覆盖发布 + 原样版本条件更新。其他提供方沿用标准规则。错误、过期和正确版本均核对实际正文及标记；任意目录 409 不作为成功或空版本放行。
