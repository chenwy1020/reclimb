## 有意义的反例

- 未核验、无密钥、零预算、AI 忙碌、读取核验状态失败时仍能保存输入。
- 保存期间继续输入、迟到反馈、切换任务、关窗重开，都保留新草稿与原记录归属。
- 回应已保存但完成标记写入失败时，事务回滚；重试不重复发布。
- 讨论输入不自动补发评分，且最终证据写入入口与备份校验均拒绝这类错误关联。
- 争议与评分同时返回时阻止无效证据；已确认纠正不因超过最近六条消息而消失。
- 篡改输入步骤、请求编号、冻结版本或讨论对应评分时，完整备份校验拒绝恢复。
- 相同来源障碍只读查看与缓存复用不收费；采用新确认来源建立新版本，旧输入不改绑。
- 关键来源未核实与模型肯定性摘要分别呈现；旧记录未知字段不补造，不给非关键旧来源增加无依据的阻碍。
- 自制 PDF 的实际第 13 页与印刷页码、公式、原页跳转、缩放和侧栏稳定性通过。
