# 重登 0.5.1 验证记录

## 范围与故障依据

用户反馈：WebDAV 保存后难以重新编辑，首次检查返回 HTTP 409，不能上传；要求设置功能卡片默认折叠，并按小版本验收。

本机配置元数据表明尚无成功上传或共同版本；已有诊断不包含 WebDAV 请求明细。旧实现先读取 head.json，只有进入上传后才建立父目录。在有真实父目录规则的自制 DAV 服务中复现了相同的 409 阻断。原生 details 在隔离桌面可以展开及填入，未复现稳定的“完全不可编辑”，故没有把 React 重绘臆断为根因；新显式编辑按钮与状态消除了入口不明显和隐含折叠状态。

修复后，检查正常已有版本保持只读；收到 409 时准备应用子目录再读一次。持续 409 不当作空档案；基础目录不存在时提示调整地址。上传前仍验证原版本、备份与条件更新，保留预算和数据约束。依据 [RFC 4918 §9.3](https://www.rfc-editor.org/rfc/rfc4918.html#section-9.3) 的父目录要求处理 MKCOL。
