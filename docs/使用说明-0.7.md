# 重登 0.7：知识图谱版

0.7 为个人本地学习加入了“学习关联”。它把不同项目中的学习目标、材料、原作答、具体表现和教学版本联系起来，帮助你判断旧经验能否带到新的学习中。关联和查找在本机完成；生成短验证仍使用你配置的模型。

## 从旧经验开始一次新学习

1. 在“学习路线”或学习工作台展开“学习关联”，选择当前要学的能力。
2. 查看其他项目的候选。名称不同也能通过搜索名称或项目关键词查找。
3. 对照两边的定义、学习目标、材料来源，以及旧项目的具体表现。可以打开来源材料，或进入原项目查看原作答。
4. 选择关系并写下理由：“能力对应”表示行为要求相当；“内容相关”保留有意义的联系；“前置基础”的方向是来源能力支持当前能力。
5. 确认后，如果来源有有效的无帮助表现，可点“先做短验证”。软件生成并核验一道新的短任务，然后进入当前项目的学习工作台。
6. 先独立尝试。新的表现仍须由本次作答产生，关联不会直接增加掌握记录。

确认关系和查找候选不调用模型。短验证会产生正常的生成与核验用量，受原预算设置约束。首版不自动分析全部材料来创建大量关系，也不自动合并同名能力。

## 能看到什么

- **当前能力与先修缺口**：区分尚未验证、帮助后完成、当前项目已有独立表现、旧项目已有表现但当前待验证，以及依据需要复核。“尚未验证”不等于不会。
- **具体表现**：显示时间、帮助程度、结果和原评价的限制。一次成功始终受当时任务条件限制。
- **关系决定历史**：确认与撤回都有理由和时间。重新确认产生新的决定，旧决定仍然可查。
- **局部关联图与文字说明**：沿材料、教学版本、作答、表现、能力和学习单元查看附近关系。连线不表示掌握。
- **曾经引用这些依据的教学**：记录实际生成时参考过哪些旧表现。仅确认关系还不算实际使用。

“内容相关”和“前置基础”帮助理解联系及补学方向，不转移能力证据。跨多个关系间接相连也不会自动认定能力相同。模型每次只接收有限数量的公开表现摘要和旧任务正文；私有核验答案不会作为图谱记忆发送或展示。

## 纠错与范围变化

发现不适合时，展开关系中的“撤回关联”，说明理由即可。能力定义、目标、材料范围或已确认转写变化后，相关确认可能需要重新核对。旧来源的评价被纠正，或来源项目进入最近删除时，旧依据也会停止用于新的短验证。

如果某次教学已经参考过这些旧依据，软件会显示复核提示，并保留当时的引用历史、原作答和后来真实产生的新表现。正在生成的任务如遇依据改变，会停止采用过时结果，保留原进度；已经发生的模型请求仍按实际用量记录。

永久清除来源项目后，其他项目只保留当时使用的公开摘要和“来源不可用”状态。若需把相关摘要也一起移除，应清除保存该历史的目标项目；永久清除前请自行决定是否保留完整备份。

## 档案与升级

本版数据库和完整备份格式为 **12**。继续使用本机 SQLite 文件保存资料，不需要另装图数据库服务。打开旧档案时先保存迁移备份，再升级；旧版完整备份可以恢复并升级。

完整备份、恢复、可读导出和 WebDAV 档案接续包含新的关系决定和引用历史。多电脑使用时请全部升级到 0.7。0.6 不支持格式 12；需要回退时，应使用升级前另存的备份或本机迁移备份，不要把新档案交给旧版写入。

本次版本的可复现验证范围见 [0.7 验证记录](验证记录-0.7.md)。模型能否为你的教材选出合适的新任务、长期是否减少重复学习，仍需要真实使用检验。
