## 新增的关键反例

- 首次只有一个路线入口；全书地图、三个稳定学习单元和主线位置同时落盘。
- 调整路线只建立提案；迟到生成不覆盖当前位置，采用后旧单元、会话和草稿仍保持关联。
- 同一输入产生的“学习者作答”和“已核验表现”不会被算成两次重复；两个不同任务的同层操作才会触发提高要求。
- 换数字或改写措辞不构成进阶；挑战必须提高推导、连接、迁移、综合等要求。
- 挑战未完成后只补评价指出的具体缺口；题目争议或来源不确定的观察不会触发降级训练。
- 直接进入下一单元不会把原单元标为完成；重启后首页从持久主线继续。
- 学习者理解稿本地保存不调用模型、不产生证据；AI 建议和学习者修订版本明确区分。
- PDF 原始 `+`、编号和断行不进入 Markdown 列表或 KaTeX；OCR 可疑页以原页为主，整页与局部确认分别版本化。
- 格式 4 升级前保存精确数据库副本；格式 1 至 5 的完整备份保持材料与新增关联。
- 启动迁移不再把旧项目伪装成最近学习；窗口关闭会等待当前主线草稿落盘。
