# 重登 0.7 知识图谱版设计

用户已认可跨材料复用学习成果的升级理由，并于本轮明确授权制作及提交独立分支。此规格将已认可的方向落实为可交付范围，不增加外部服务或自动联网操作。

## 目标与基线

- 基线：0.6.0，提交 `12ab825`；开发分支 `codex/reclimb-knowledge-graph`。
- 交付版本：0.7.0。本地 Windows x64 Electron 应用，沿用 TypeScript、React、SQLite/sql.js。
- 用户收益：跨项目发现可参考的旧学习记录；确认能力对应后，在新教学中先做必要的短验证；解释具体缺口；旧依据纠正或关联撤回后显示影响范围。
- 不将关联确认或旧项目表现计为新项目的掌握证据，不自动跳过学习单元，不引入图库服务、Python 或全书 AI 抽取费用。

## 图模型与持久化

图节点从已有能力、材料片段、教学版本、作答、证据和学习单元生成；节点使用稳定实体 ID，关系含明确类型。保留“能力是行为目标，证据是有时间与帮助条件的一次表现”的边界。

新增两类持久记录：

1. `knowledgeRelations`：跨项目的能力关系决定。`projectId` 为目标项目，`sourceProjectId` 为来源项目；保存源/目标能力、两端范围签名、用户确认理由、关系种类（equivalent、related、prerequisite）、时间、稳定 rootId、前一决定 previousId。confirmed/retracted 均以新决定追加，旧记录不覆盖。能力的定义、目标或材料范围改变后，旧对应需要重新确认。
2. `knowledgeUses`：某教学版本实际使用过的历史上下文。记录目标教学版本、引用的关系决定、旧证据 ID、冻结的公开摘要、时间。只含可公开的表现信息，不含核验私有答案。来源被清除时仍保留使用历史，查询时明确标记来源不可用，不再作为有效依据。

候选发现为本地、确定性的文本匹配，支持手动搜索不同名称；候选不具有事实效力。只有用户确认且两端范围未变的 equivalent 关系可提供跨项目表现背景。related/prerequisite 可用于解释关联和补学方向，不作为等价能力证据。所有证据重用均检查原项目可见、帮助条件、实际 assessment 和现有 evidenceStanding。

SQLite schema/备份格式升级为 12；升级前保留原始库副本，旧备份补空集合，旧 WebDAV 内容 hash 保持兼容。新数据进入完整备份、恢复、同步、可读导出及项目清除流程。清除源项目时移除跨项目关系端点引用，保留其他项目内教学使用的冻结摘要并标记其依据不可用。

## 查询与教学整合

共享纯函数返回图、候选关系、能力依据、先修缺口与受影响教学记录。图遍历必须防环，查询按项目和当前能力限制显示范围；不通过无限传递的“同义”推断自动合并能力。

学习活动生成时加入 `priorLearning`：来源项目、能力描述、表现日期、帮助状态、依据 ID、关系说明，以及“仅用于选择短验证，不等于当前能力已掌握”的约束。候选或撤回关系不进入可复用证据。显式“先做短验证”使用新的 independent/check 教学流程，当前证据只有实际新作答才产生。

模型调用开始与结果发布之间重新检查历史上下文；若关系、证据有效性或能力范围改变，拒绝发布过时结果，保留旧档案。教学版本发布后保存 knowledgeUses，图查询和当前会话显示失效依据影响提示。纠错不自动改写原作答，也不把一条旧依据失效解释成用户不会。

## 用户界面

在现有路线/学习界面增加“学习关联”入口：按当前能力显示旧项目候选、定义与目标对照、证据状态和来源；允许选择对应/相关/前置、填写理由、确认与撤回。可搜索其他名称以建立关联。

显示当前能力及先修的状态：尚未验证、帮助后完成、当前独立表现、旧项目有独立表现待本项目短验证、依据需要复核。提供“查看旧作答”“返回来源项目”“先做短验证”等可用操作，保留现有导航与草稿。

局部图以少量节点和有名称的连线解释来源→作答→证据→能力→当前目标；同时提供可访问的文字列表，不强迫用户维护大图。纠错影响显示引用旧依据的教学记录及原因。

## 验收

- 同名能力只产生候选，未确认时不会输入为已建立对应的教学背景。
- 确认不同名称的对应后，来自另一项目的有效表现进入新任务上下文；不创建新 evidence、不改变新项目完成状态。
- 有提示、无帮助但未达标、已纠正、旧版本未通过核验、回收站项目、范围变更各自显示准确状态。
- 短验证不提前讲解解法，不自动复用旧题为新成功；新作答沿原有核验链形成独立证据。
- 关联撤回/原证据失效后旧使用记录显示复核原因，新任务不再采用这些依据；进行中的模型结果不能悄悄发布。
- 图关系追加历史、重开、v11迁移、备份回灌、旧同步 hash、跨项目清除得到自动测试。
- 完整单元测试、类型检查、构建与真实 Electron 本地模拟流程通过；使用合成学习材料，外部模型请求为 0。
- 版本号、使用说明、验证记录、可运行安装包与新分支提交相互一致；未验证的真实模型教学效果明确记录。
