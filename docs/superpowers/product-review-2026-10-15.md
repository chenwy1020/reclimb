# 第二轮产品评审处理记录

输入：针对提交 `0c5c910` 的 0.7.1 产品评审和标注图。报告作为待核验的产品建议，不作为收费、部署、覆盖发布附件或上传学习档案的授权。用户明确没有服务器；本轮采用本机排程、应用内提醒和用户已有模型连接。

## 采纳与取舍

| 建议 | 处理 |
| --- | --- |
| 当前任务被元信息挤出首屏 | 采纳。任务、题干、作答与单一主按钮前置；材料、求助、笔记、规划、会话、核验与历史进入可关闭工具区。 |
| 同一反馈出现三次 | 采纳。当前评价只渲染一次；步骤历史、输入历史和关联证据去重，原答与逐项标准在同一反馈内展开。 |
| 两个主按钮、核验卡片贴边 | 采纳。提交是作答步骤唯一主按钮，继续为次按钮；详情标题补水平留白。 |
| 窄窗阅读器盖住任务 | 采纳。1040 窗口同样任务优先；阅读器按需打开并保留材料、页码、滚动、转录编辑。 |
| 免责声明过多 | 采纳主流程减负。尝试中、有帮助完成、独立完成、经过回访四类状态；待复核保留明确标记。详细条件集中于核验、反馈详情和实际操作处，见下表。 |
| 回访仅一次 +1/+7 | 采纳。连续 1/3/7/30/90 天排程，独立通过延长，有帮助维持，明确失败 24 小时后复学；不确定评分不擅自改期。 |
| 已独立完成能力应始终有下次日期 | 采纳。补齐有效旧记录；保留旧 +1/+7 邀请，完成旧队列后续接连续排程。暂停、删除、归档或依据失效时停止使用。 |
| 回访 3–5 分钟、交错能力 | 采纳。提示与生成结构要求一项短 check、最多两项标准；到期队列按能力交错，首页估计每项 4 分钟。 |
| 到期数量、时长、每周指标 | 数量原已存在，补时长和本周按期无帮助通过次数。按本机日期计算，不上传分析数据。 |
| 系统提醒 | 采纳本机方案。默认关闭，用户设定时间，应用运行时每天最多提醒一次。退出应用后不提醒，不部署常驻服务器。 |
| 首次配置更简单 | 采纳。快速连接只填服务地址、模型、密钥和明确预算；测试成功后可启用。高级价格与参数仍可编辑，原配置不覆盖。 |
| 服务商预设、自动价目表 | 调整采纳。支持任意兼容服务，但没有把未经实时核对的价格写成官方价；占位估算明确标注。 |
| 安装后先体验价值 | 采纳。首页突出内置原创示例，直接进入学习台，未配模型也能阅读并保存首次作答。真人首次使用五分钟目标仍待测量。 |
| 十秒内流式讲解、后台核验 | 暂不宣称达标。现有生成与核验是结构化结果，保留评分前核验闸门；未把未核对的私有内容或半截 JSON 直接展示。真实耗时单独测量。安全流式展示另行维护协议。 |
| 20×4 原创模型评测进入手动 CI | 采纳。默认离线校验，显式执行才收费；运行真实生成、核验、评分与讨论路径，结果保留失败和待评阅状态。 |
| 两周自用、3–5 位学习者试用 | 保留为实测任务。软件与模拟检查不能产生这段时间的真人数据。 |
| 自动关联、砍掉手工确认 | 不直接采纳。名称相似或一次短测不足以证明能力等价；保留短验证、确认与撤回。关联入口退出任务主区，移入工具和路线页。 |
| 溯源图文字截断、边标签压线、节点被裁切 | 采纳。节点完整换行，尺寸随节点数增长，可横纵滚动；连线名称放在文字说明与悬停信息。名称明确为证据溯源图。 |
| 新能力地图 | 按评审的后续路线暂缓；现有溯源图不冒充能力地图。 |
| 考试模式 | 本轮先采用独立步骤默认专注作答，可主动退出并使用帮助，实际帮助仍记账。它不冒充正式开卷/闭卷考试。 |
| 信心校准、FSRS、Anki、macOS、签名 | 暂缓，避免在本轮核心减负中扩展新系统。 |
| 反馈回答目标、表现、下一步 | 采纳。当前反馈分三部分，完整标准与限制按需展开；学习记录按能力分组并显示下次到期。 |
| 公式输入与设置分类 | 采纳。公式实时预览、常用符号；设置分学习、AI 与费用、数据与同步，切页签保留未保存输入。 |

## 验证与边界

产品桌面夹具在 1440×900、1280×800、1040×800 下实测任务、题干、完整输入与提交按钮在首屏；默认任务控件 11 个、一个主按钮、反馈 DOM 一份，反馈页约 1301–1321 像素。长题保留完整题设，不以截断内容满足高度指标。这些数值只对应固定原创夹具。

连续排程覆盖独立、有帮助、失败、不确定、旧双回访、撤回后补齐及备份引用；提示默认关闭并覆盖跨日、重启和失败保存。桌面回归继续检查材料滚动/页码、快速关开工具、原稿、转录、草稿、回应重试、关系撤回和旧档案恢复。

2026-10-15 用户另行明确授权使用保存的 Magpie 连接与 `deepseek-web/deepseek-reasoner`，不限本轮预算。执行仍采用每格有限费用预留、独立原创档案和受控并发；密钥不输出、不进入报告。真实模型结果按实际报告补入，不把自动评阅写成人工一致率。已发布 0.7.1 标签及附件保留。

本轮已生成 30/80 格基线报告，其中 16 格有实际结果、14 格执行错误；后续两次探针均返回空正文，已停止调用。发现短验证标准超限后补结构约束和一次修正；针对评分额外要求与无关假设造成的误阻断补充核验规则，保持未知条件闸门。修复后真实复测仍未完成，不宣称模型质量通过。费用、分母与剩余验证详见 [0.8.0 验证记录](../verification/验证记录-0.8.0.md)。
