# Task 2：教学接入与桌面接口

实现以 `12ab825` 的 0.6 为基础，沿用本机存储、生成预算、独立核验、原作答与评价链。

- 主进程支持 `knowledge.view/confirm/retract/check`。确认和撤回为本地操作；短验证受现有模型并发及预算限制。
- 生成教学时冻结有限的 `priorLearning.entries` 与指令，模型只读取公开摘要和历史任务正文。本机完整范围签名不送模型。
- `startKnowledgeCheck` 要求有效直接对应的旧表现，创建新的单 check、短任务、最多两项标准，无预先讲解；更新学习位置而不复制证据。
- 普通教学、局部教学恢复、下一步和纠错修订记录实际使用的历史依据。生成完成及发布时再次核对；关系、范围或表现改变则拒绝旧结果。
- 学习建议分析也可参考历史；`knowledgeBasis` 保存本机摘要校验值，随建议采用进入学习位置。撤回后建议与位置暂停采用，作答及真实表现不变；完整备份保存该依据。
- 新会话、下一步和纠错替换的发布与 `knowledgeUses` 在同一事务中保存。未采用的生成结果标记 `discarded`；实际已完成的调用费用仍保留。

独立审查修复 `f2fab59` 使后续强制核验、争议核验和来源修订沿教学版本链恢复旧题上下文；撤回关系不会让用户已见过的旧题消失。没有完整旧题正文时不冒充已验证的新任务。私有解答不进入图谱背景。
