# 重登 0.5.0 验证记录

大版本范围：原生笔触接续、专注书写、手写原位追问、iPad Markdown/数学阅读、WebDAV 完整快照与多电脑接续、iPad 多标签冲突副本。

## 验证依据

用户提供的真机对照为 Air 5、二代 Apple Pencil、开启系统随手写：手指流畅，笔连续书写仍受干扰。此前 0.4.10 的合成 PointerEvents 通过不能证明此故障已解决。本版增加原生 stylus TouchEvents 与 PointerEvents 的接续、重复排除，以及显式专注模式。

完整基线为 638 项，635 通过；两个旧数据库断言仍预期版本 7，另一个预算断言未包含结构合同及消息边界。核对实现后改为版本 9 和完整实际请求长度，继续检查原始迁移副本及费用上限，没有删除断言。

## 检查范围

- 来源核验、争议暂停评价、任务帮助、答案暴露、路线推进、理解稿、数学阅读、项目删除恢复、模型配置、预算、缓存结构、先保存后回应及备份恢复等全部现有离线测试。
- 累计桌面组从 0.4.4（包含 0.3.1/0.4 核心流程）到 0.4.10，再增加笔触、手写追问、双安装 WebDAV 和多标签草稿组。早期依赖私人教材的旧脚本由当前自制 PDF 与保留的离线测试覆盖，不要求外发或持有该教材。
- WebDAV 条件更新、防分叉、丢回执重试、重启恢复、弱 ETag/忽略条件拒绝、重定向拒绝、超时/取消/体积限制、损坏备份与预览后变化。
- 同步采用保留本机配置和凭据、两端费用记录、原始档案副本；先前已开始的异步保存或导入阻止工作区替换。

## 独立审查补充

审查定位并修复两个数据保护问题：同一 iPad 任务多标签保存会相互覆盖；远端档案已经采用但后续状态写入或界面读取失败时会残留旧草稿。现有事务内比较与冲突副本保留两份；采用前先持久撤销旧待上传快照，采用成功后立即清除界面旧绑定，再读取新档案。覆盖采用前落盘失败不替换、采用后连续落盘失败不复活旧上传、刷新连续失败后重新连接恢复新稿。

旧累计桌面脚本更新四处已过时的假设：从追加消息读取格式恢复数据、作答容器内寻找失败提示、新增 WebDAV 卡片后的数量，以及原稿选择器新增标识后使用固定原稿编号定位。最后一项在包内全量验收中发现，定位后用同一个安装包通过了原有 8 项手写流程，并增加任务、会话、非冲突副本身份和两次回执核对。原来源、费用、保存、布局间距断言保留。

包内验收另发现 Windows ASAR 资源提取工具使用了错误的路径分隔符；实际包已含公式样式和字体。修正测试提取路径，并在交付依赖检查中加入伴随页面入口、样式和 KaTeX 字体核对，实际包的新四组全部通过。一次全量运行的测试 Node 以 `0xC0000409` 异常退出，未报告 JavaScript 断言失败；同组独立复跑 10/10 通过，原日志保留，具体原生退出原因尚未确定。

## 尚待真实使用验证

Windows Chromium/WebKit 的合成笔事件不是真实 iPad 或 Apple Pencil 验收。当前系统随手写是否仍抢占连续落笔，需用户设备重新加载新版页面后复测。

WebDAV 验收使用本机可控服务及两个独立资料目录；未配置真实网盘账号，没有外发私人教材、手写或学习档案。没有调用真实文本或视觉模型，累计开发模型费用保持原账本额度。

安装包检查包括解包后运行实际 Electron 程序与本机依赖，不冒充全新 Windows 的安装向导验收。未执行用户电脑上的旧版卸载或覆盖运行中的个人档案。

学习效果、真实识别准确性、网络服务兼容性与成本收益仍需跨日实际使用；程序测试不作为学习成效证明。
