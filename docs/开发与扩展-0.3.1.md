# 开发与扩展

使用 Windows x64、Node.js 24、锁文件安装依赖。开发资料目录需显式指定为隔离目录，不能指向正在使用的学习档案。

```powershell
npm ci
node node_modules/electron/install.js
$env:RECLIMB_DATA_DIR = Join-Path $PWD '.local-test-data'
npm run dev
```

## 检查与构建

```powershell
npm run typecheck
npm test
npm run build
npm run test:desktop
npm run package
npm run package:source
```

桌面测试采用临时资料目录、模拟模型服务和自制 PDF，默认无外部请求。需要本机可选教材复核时显式设置 `RECLIMB_TEST_PDF`，不要提交该教材或测试输出。

`scripts/verify-package-v031.ps1` 将安装包作为归档解开，运行其中实际应用进行隔离检查，不执行安装器。它不等同于全新 Windows 安装验证。可通过 `SevenZip` 参数指定本机解压工具。

源码归档由 `scripts/source-files.mjs` 白名单决定，打包前检查明显凭据与禁止类型。增加可交付文档或脚本后，需要明确更新白名单。扫描不能代替发布前人工审查。

## 可选的真实服务验证

`scripts/run-live-validation.mjs` 要求显式传入独立账本目录、配置、自编案例、全新报告路径和累计上限。默认只做预检，加入 `--execute` 才调用真实服务；不自动查找本机应用密钥或教材。

```powershell
node scripts/run-live-validation.mjs --workspace <绝对账本目录> --config <配置JSON绝对路径> --fixture <自编案例JSON绝对路径> --report <新报告JSON绝对路径> --cap 3
```

配置字段为 `providerName`、`baseUrl`、`model`、`apiKeyEnv`、`inputPriceCnyPerMillion`、`outputPriceCnyPerMillion`、`priceUpdatedAt`。`apiKeyEnv` 指定执行者自行设置的密钥环境变量名；配置文件不存密钥。

案例字段为 `authorship: "original"`、`case: "uncertain-discussion"`、`activity: {title, instruction, rubric}` 和 `input: {kind, text}`。不支持在该工具中导入私有历史或来源。账本复用同一目录，重试不重置累计用量；工具报告保留在本机，不进入源码归档。此工具仅验证输入与回应流程，不授予题目正确或教学有效的认证。

## 核心接口

`session.recordInput` 只执行本地事务，使用客户端请求标识保证幂等，返回输入编号及回应模式。`session.respondInput` 按编号请求回应，不创建另一份作答。输入对象保存题目和步骤快照；能力证据仍通过原有严格准入规则。

模型返回状态与程序有效状态分别存储。阻断原因用枚举与来源定位表达，界面说明由安全模板生成，避免把隐藏参考答案混入普通快照。`session.verify` 默认复用相同审查；显式 `force` 才请求主动重新核验。

材料导入器、教学活动与模型提供方维持独立接口。扩展时优先新增有意义的行为回归：输入不丢、版本不混、证据不冒进；不要用镜像实现的测试替代真实反例。

## 私有阶段

仓库暂为私有，许可证为 `UNLICENSED`。公开前应选择许可证，审查第三方授权，并去标识化用于旧版定点修正的事件标识。不要删除升级逻辑来替代这一步。
